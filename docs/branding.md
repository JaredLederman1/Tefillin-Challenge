# Levav

Levav is the app name and customer-facing brand. Use this spelling in UI, checkout, support copy, and future artwork. The blue tefillin symbol remains the core logo.

The existing Expo project slug, native bundle identifiers, Supabase project reference, payment metadata and device storage keys are retained for continuity with existing builds and data. These are technical identifiers, not display names. Both levav and the legacy URL scheme are registered; legacy payment redirects remain compatible with existing development builds. Native display-name and URL-scheme updates require rebuilding the app.
